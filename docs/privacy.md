# Privacy and publication boundary

This public Personalized AI Mentor package was generated from a private working project, but it does not include the private learner state.

## Excluded from the public repository

- Real names or collaborator names
- Employer or client affiliations
- Research topics, manuscripts, or compliance submissions
- Private product names
- Exact deadlines, daily schedules, and progress history
- Career-search details and personal role targets
- Health, energy, sleep, exercise, or recovery information
- Private roadmap, progress ledger, and state audits
- Local attachment paths and machine-specific paths

## Included

- The skill architecture and runtime instructions
- Public-source records and provenance
- Evidence cards, synthesis, and behavioral model
- Session, policy-selection, style, and state-update logic
- Selective RAG configuration and local retrieval code
- Fictional example state used only to demonstrate the schema

## Publication rule

Treat `skill/state/` as an example schema. Keep real state in a private copy or a gitignored `private-state/` directory. Before every public push, scan for names, organizations, project titles, email addresses, credentials, local absolute paths, and dated personal events.
